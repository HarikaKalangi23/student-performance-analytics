# Student Performance Analytics System

## Project Overview
A Python-based project that analyzes student academic performance using NumPy and Pandas.

## Objective
To calculate total marks, average marks, grades, pass/fail results, subject-wise performance, and identify top-performing students.

## Technologies Used
- Python
- NumPy
- Pandas
- CSV

## Dataset
The `students.csv` file contains 20 student records with student ID, name, department, subject marks, and attendance.

## Features
- Student data loading using Pandas
- Total and average marks calculation
- Grade assignment
- Pass/fail analysis
- Class performance summary
- Subject-wise average analysis
- Top five student identification
- Export of analyzed results to CSV

## Grading Rules
- 90–100: A+
- 80–89.99: A
- 70–79.99: B
- 60–69.99: C
- 50–59.99: D
- Below 50: F

A student passes if they score at least 40 marks in every subject.

## How to Run
1. Install Python.
2. Install dependencies using `python -m pip install pandas numpy`.
3. Keep `main.py`, `functions.py`, and `students.csv` in the same folder.
4. Run `python main.py`.

## Project Files
- `main.py`: Main program
- `functions.py`: Reusable calculation and analysis functions
- `students.csv`: Input dataset
- `student_analysis_results.csv`: Generated output
- `README.md`: Project description
